# Gate G2

Result: **the GPUI shell draws the named scenes in a headless window.** It does not connect to a pool. The Rune binary `xenadmin-rs` stays the released artifact. `xenadmin-core`, `xenadmin-xapi`, and `xenadmin-process` were not modified.

## What the shell does

`xenadmin-gpui` opens one window. Menus come from `xenadmin_ui::COMMANDS`. A command that is hidden for the selection is omitted. A command that is disabled shows its reason and is not clickable. The toolbar has Add Server, Back, Forward, and Start. Start appears only when the selection is a virtual machine, and its dialog does not call a host. Back and Forward walk the selection history. The navigation tree is the shared infrastructure tree. The tab strip follows the shared tab matrix. Search shows the shared guest rows. General shows the selected object's name and power state. The status bar says the preview is not connected, and it names a host whose version is outside the 8.3 line.

`--version` prints and exits before a window. `--demo` and `--scene` load `load_scene`. `--theme light` switches the Kit theme. The guest cursor is not drawn. Route A, the second `wl_keyboard`, is unchanged.

## Scenes

`tests/phase2_shell.rs` (`cargo test -p xenadmin-gpui --features scenes`) renders these scenes and finds a marker in the element tree: `demo`, `connect`, `connect-insecure`, `large-inventory` (2,000 guests), `connections`, `connection-settings`, `connection-trust`, `certificate-review`, `host-version-notice`, `inventory-context`, `general-information`, `search-pools`, `unavailable-actions`, `interface-large`. The same test switches the Kit theme to light and back to dark. A second test moves the tree and the grid with the Down key and opens Add Server.

PNG bytes are not produced. `gpui-pre-linux` 0.3.12 does not export `current_headless_renderer`, so the scene tool cannot install one without a direct `gpui-pre-wgpu` dependency, which this port does not take. The proof is the element tree.

## Accepted limits

These need a person, a lab guest, or a focused Wayland seat. They are recorded and are not a stop.

- No lab pool connection, pinned certificate, or live inventory update.
- No Wayland focus proof. Headless output does not establish Wayland, the system clipboard, physical keys, or Orca.
- GPUI pointer delivery was not shown.
- There is no hidden cursor style. The GPUI console does not draw the guest cursor. The Rune console still draws it.
- Screencopy frames were not read back.
- Clipboard without focus was not shown.
- Fullscreen enter and exit was not shown.
- Single-instance activation, the development inspection socket, saved preferences, and the navigation collapse below 1100 px are not in this shell.
- `interface-large` renders the same shell. It does not reflow to 800x600.
