# Home-host affinity — 8 November 2026

VM properties now offers a captured pool-host picker and an explicit no-preference
choice. Review names the original and requested host UUIDs and explains that affinity
is a hint for future starts, not migration or a placement guarantee. This follows the
[XAPI VM affinity contract](https://xapi-project.github.io/xen-api/classes/vm.html#rpc-set_affinity).

The public settings patch contains typed host UUIDs. Core resolves the current host
reference to its UUID before preflight and reconciliation, resolves the requested
UUID again before the setter, and verifies the resulting UUID afterward. Unknown
inventory is distinct from a known null preference. Changes require an ordinary
halted or running VM and its captured connection generation. No power or migration
operation is dispatched. Lost replies retain the existing settings reservation;
reconciliation reads values without repeating the setter.
